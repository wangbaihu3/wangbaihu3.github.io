为什么没有谷歌／微软声音？

本播放器只显示当前浏览器实际提供的声音。谷歌／微软声音按名称归组；联网声音会显示在列表中，但需要先勾选许可，不能用隐藏按钮假装可用。

Windows 可在 Chrome 中检查 Google 声音，在 Edge 中检查 Microsoft 声音；不同系统与版本不保证提供相同清单。切换声音来源后可按“刷新声音列表”。未提供时会明确显示 0 个，不自动改用另一厂商。

Edge 自带的“朗读此页”还有独立的声音选择，可从浏览器菜单启用；本网页不能替你自动打开浏览器菜单。Google Cloud TTS 与 Azure Speech 是另需授权的云服务，本静态包未配置或宣称已接通。
