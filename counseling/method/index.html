在真理中重塑生命 · 七阶辅导方法

从真实处境，走向福音中的实际改变

从事实、解释、欲望和理由，走到真实悔改、基督的恩典与具体顺服。这里把七个阶段与二十四个问题展开为可以阅读、讨论和调整的辅导方法。

先选一个真实而具体的问题，不必一次审问自己的一生。方法以圣经为规范；七阶只是帮助思考的次序，可以停下、回看或寻求陪伴。若事实尚未清楚，先核实；若正在受伤害、疾病或危险中，先得到合宜关怀。以下涉及罪责的问题，只用于自己已经确认的具体选择。

按实际问题阅读专题使用逐步辨析入口需要立即帮助

七个阶段

  1. 第一阶：把处境和事实说清楚
  2. 第二阶：查验我怎样解释这件事
  3. 第三阶：看清欲望与它许下的承诺
  4. 第四阶：用真理检验我的理由
  5. 第五阶：承认责任，转离已经明确的罪
  6. 第六阶：在基督里领受恩典与新身份
  7. 第七阶：脱去、更新、穿上，并持续复核

第一阶：把处境和事实说清楚

经文范围：箴言18:13、17；雅各书1:19；加拉太书6:1—2

把最近一次具体事件放在面前：谁在什么时候说了什么，我做了什么，哪些是亲眼所见，哪些是推测。聆听不是暂停圣经的权威，而是承认我们不能凭空知道事实。箴言18章提醒人不可未听先答，也不可把先听到的说法当成全部材料。

身体紧张、悲伤、疲惫能提示我们需要照顾和理解，却不能证明隐藏的偶像或某项罪。先分别记录遭遇、感受与自己的选择；别人的伤害和我的回应可以同时存在，也要分别判断。加拉太书6章既讲挽回真实过犯，也讲担当重担，两者不能互相吞没。

可自愿选择的问题

  1. 事情具体发生在何时、何处？我能准确写出哪一句原话、哪一个行为？
  2. 哪些是已经核实的事实，哪些是自己的解释，哪些还不知道？有什么证据可能改变我的判断？
  3. 当时的身体状况、疲劳、受胁迫或能力限制如何影响选择？现在是否需要先获得保护或照护？
  4. 我需要承担哪一部分责任？哪些属于别人的责任，不能靠强迫自己认罪来解决？

落到今天的一步

用四行作简短记录：发生的事、我的回应、仍未知的事、眼前需要的帮助。没有必要把私人记录填进网页；也不必挖掘所有过去经历。

虚构贯穿案例：小林知道实际报销额是80元，却提交了180元。他保留的收据和提交记录可以核实。先确认金额、时间、知情和自主选择；不是因为他紧张，就认定他撒谎。

第二阶：查验我怎样解释这件事

经文范围：以弗所书4:17—25；罗马书12:1—2

行为往往连着解释：我把别人的不同意见解释成羞辱，把受损解释成可以报复，把承认错误解释成彻底没有价值。要辨明心里的话，不能由辅导者替当事人编造动机。先让真实想法说出来，再用经文检验。

以弗所书4章把心志更新与脱去旧人、穿上新人连在一起，随后给出诚实、劳作、分享和造就人的言语等具体方向。更新不是给旧做法换一个属灵名称，也不是否定一切真实需要；它改变的是我对需要、权利和邻舍的理解。

可自愿选择的问题

  1. 那一刻我实际对自己说了什么？我能分清记得的话和现在猜测的话吗？
  2. 我是否把一个合理愿望变成了“别人必须满足我，否则我就可以犯罪”的规则？
  3. 我给自己的行为起了什么名字？这个名字是准确描述，还是替已经知道的错误开脱？
  4. 还有什么更符合证据的解释？如果判断错了，我愿意修改什么？

落到今天的一步

选一句最影响行动的内心话，写清其中的事实、愿望和结论。再用完整经文说明哪一步推理站不住脚，避免只写“我要有信心”。

小林的内心话是：“公司对我不公平，这100元算它欠我的。”不公是否存在需要另查；这句话却把未经确认的债务变成了私自伪造报销的许可。

第三阶：看清欲望与它许下的承诺

经文范围：雅各书4:1—10；马太福音6:19—24

雅各书4章针对群体中的争战和私欲，揭露人怎样为所求之物争夺。它适合检验争竞中的欲望，却不能被扩大成“一切痛苦都证明你拜偶像”。渴望被尊重、得到供养、恢复安全本身未必邪恶；要查验的是我怎样追求它，以及是否愿意为它伤害人、违背真理。

所谓假应许，是我指望一个受造之物提供它无法承担的终极安全、身份或满足。有时罪带来短暂利益，这正是诱惑的力量；真实省察要把短利、代价和重复后的后果一起看清，而不是只喊“这个欲望不好”。

可自愿选择的问题

  1. 我想得到或保住什么？这个愿望本身是否正当？
  2. 为了得到它，我实际选择了什么手段？我是否把别人当成工具或障碍？
  3. 这项做法当时给了我怎样的短暂好处，又让谁承担代价？
  4. 我盼望它最终保证什么？实际结果是否兑现，还是让我更需要隐瞒、控制或重复？

落到今天的一步

把“想要什么”和“用什么手段得到”分开。保留正当需要，停止有罪手段；具体写出被损害的人和可以修复的事。

小林得到100元和片刻“扳回一局”的满足，却要维持假记录，也使审核同事承担错误。他真正需要的是公正待遇，但伪造并不能建立公正。

第四阶：用真理检验我的理由

经文范围：以弗所书4:25、28—32；彼得前书2:21—23

这一阶检验的是理由是否与圣经及事实一致。若我主张“被亏待就可以欺骗”，这条规则也会许可别人以同样理由欺骗我。指出这种矛盾是帮助人看见问题，不是用巧辩压倒对方。凡缺少证据的前提，都可以撤回。

基督受苦而不以恶报恶，显明信靠父和行义可以并行。但基督的受苦不可被用来逼受害者留在危险中、放弃申诉或帮助侵害继续。经文要求拒绝报复，同时也要求说诚实话、爱邻舍、停止伤害。

可自愿选择的问题

  1. 如果人人都按我刚才的理由行事，会怎样对待真理、邻舍和责任？我是否采用了双重标准？
  2. 相关经文在上下文中实际要求什么？我是否把个人建议误当成神的命令？
  3. 有没有一个反例或新事实，足以推翻我的理由或辅导者的判断？

落到今天的一步

选择一段直接关联行为的经文，写两句：经文原本在说什么；它怎样约束这次选择。不要靠堆砌经文数量增加压力。

以弗所书4:25把诚实放在彼此为肢体的关系中；4:28从停止偷取进到劳作并分享。小林不能用“我觉得公司亏欠我”取消诚实，也可以另循正当渠道提出薪酬争议。

第五阶：承认责任，转离已经明确的罪

经文范围：诗篇51篇；哥林多后书7:10—11；路加福音19:1—10

悔改包括认识并厌恶罪、转向上帝、停止继续做，并在合宜范围承担现实责任。害怕被发现、只对损失懊恼、笼统说“我什么都错了”，都不能代替具体转离。也不可用哭泣程度、措辞流畅或完成清单来测量悔改是否真诚。

接受基督的主权，意味着让他的道纠正我，也意味着辅导者的权柄受同一道约束。人不能要求另一个人把自己的良心绝对交给他。对确认的过犯应诚实；对没有做过的事不作虚假认罪；面对指控与不公仍可以澄清、申诉和寻求合宜保护。

可自愿选择的问题

  1. 我已明确知道哪一项具体行为有错？我是否正在停止它，而不只是讨论它？
  2. 认罪、道歉、纠正或赔偿应向谁进行，涉及什么事实？怎样避免披露无关隐私、给受伤者再添负担？
  3. 我还有什么借口正在保护旧行为？面对应承担的后果，下一项诚实行动是什么？

落到今天的一步

写一段具体而简洁的承认：我做了什么、怎样伤害人、会停止什么、如何纠正。不给对方设置必须立即谅解或恢复信任的期限。

小林向负责报销的人说明真实金额，提交更正并归还多领款项，不把责任推给薪酬不公，也不要求同事立即恢复原来的信任。

第六阶：在基督里领受恩典与新身份

经文范围：罗马书3:21—26；8:1；以弗所书2:8—10；提多书2:11—14

福音不只是行动计划前的一句“靠主加油”。基督真实的代赎是赦罪的根据；称义是神因基督称信他的人为义，不是人凭修复记录换取的无罪证明。悔改与信心不可被拆开，修复也不能变成自己偿还神面前罪债的方法。

可以从四方面具体思想：基督的属性——他真实、信实、怜悯、公义；基督的救赎——他承担罪的刑罚并以义遮盖信他的人；在基督里的身份——蒙赦免、被收纳而学习新生活；基督的呼召——因已蒙恩而诚实、爱人并承担责任。恩典没有取消义务，却改变我们顺服的根基与盼望。

并非每位读者都已表明信靠基督。因此不能仅因按完七个步骤就替人宣布得救；也不能因信徒仍有痛苦和争战就立即推翻其信仰。把人引向基督的应许、教会中的讲道与圣礼、祷告和可信牧养，不以软件结论代替信心。

可自愿选择的问题

  1. 我现在是靠什么寻求神的接纳：基督已经成就的救赎，还是自己的表现与补偿？
  2. 哪一项关于基督的真理，具体回应了前面那个虚假的承诺？它怎样改变我今天的选择？
  3. 我怎样在信靠基督中接受帮助、承担责任，并把判断自己身份的重担从表现记录上移开？

落到今天的一步

把一项福音事实和一项具体责任并排写下，例如“赦罪倚靠基督；我因此可以诚实更正账目”。不要把顺服当作应许必有好结果的交换条件。

小林不再靠维持“从不犯错”的形象争取价值，也不把归还100元当作买回神的恩典。他信靠基督，并愿意面对纠正之后仍可能存在的工作后果。

第七阶：脱去、更新、穿上，并持续复核

经文范围：以弗所书4:22—32；歌罗西书3:12—17；加拉太书6:1—2

改变要落在同一处境中的不同选择。“不再撒谎”需要落实为准确记录、及时说明和愿意核实；“不再发怒伤人”需要落实为停止辱骂、说明合理需要、听对方说完并作修复。积极顺服不只是给旧行为加一个禁令。

把计划缩到今天可行的一步，同时预先安排下一次诱惑来临时的帮助。跟进要看行为、关系影响、事实和支持是否改变，不只看感觉。再次失败时，应停止伤害、具体承认、修正计划；不要把失败美化，也不要宣告一切成长都作废。

可自愿选择的问题

  1. 下一次同样处境来到时，我具体停止什么、记起什么真理、选择什么正当行为？
  2. 哪些环境安排和可信同伴能帮助我实行？我可以怎样自愿求助，而不交出不必要的隐私或被控制？
  3. 何时复核？我会查看哪些实际变化，哪些新事实会使计划需要调整？

落到今天的一步

形成一条简明计划：当＿＿出现，我先＿＿，依据＿＿，改做＿＿；必要时向＿＿求助，在＿＿复核。计划可调整，不设得救分数、不追求完美打卡。

小林保留实际收据，提交前对照金额；对报酬的不满另约时间表达，不再暗中补偿自己。一周后核实更正已完成，并讨论怎样在受委屈时仍保持诚实。

怎样与他人一起使用

辅导者先听清当事人希望解决什么，确认谈话范围和保密边界；一次只选择适用的阶段。会谈结束时，用当事人能理解的话确认一项需要停止的行为、一项可以实行的善行、一项现实支持和一个复核时间。下次先问实际发生了什么，再决定是否继续原计划。

若本人遭受伤害同时也有不当回应，要分别处理。不要因受害就取消其真实责任，也不要因其有过犯就取消保护。信任恢复、关系和好与赦免的处理需要时间、事实和合宜条件，不能用一句“已经饶恕”强迫回到危险关系。

本页的方法来源与核读范围

本页根据用户提供的《改革宗心灵辅导核心理论自我辅导》七阶段二十四问与《圣约性荣曜治理系统 V50.0》中的属性、恩典、更新、差遣结构，重新编写为原创中文教学。保留对解释、欲望、假应许、福音和习惯的深入查验；纠正将身体反应、遭遇痛苦或受害身份直接当作罪证的推论。原文件未改写。

相关研读线索：欧文《内住之罪》论罪从诱惑至意志同意的进程；《论试探》对受试探与进入试探的区分；华森《悔改的教义》第三至四章的悔改要素；弗拉维尔《保守己心》关于具体处境中的警醒。这里是主题整合，不是这些书的逐章译文或全本审定声明。

教义对照：《威斯敏斯特信条》第十一、十三、十五及二十章；《大要理问答》第144—145问。经文按其上下文应用，不以术语替代事实。
